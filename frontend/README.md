# TechStore · Frontend

Interfaz React en español, Vite y Tailwind CSS. Ejecución local desde esta carpeta:

```powershell
npm install
npm run dev
```

Abre http://localhost:5173 con Django iniciado en http://localhost:8000.
`VITE_API_URL` es opcional; por defecto usa `http://localhost:8000/api`.
No coloques secretos OAuth en este proyecto. Usa siempre `localhost`.

```powershell
npm run build
npm run lint
```

La guía principal, cuentas demo, MFA y callbacks OAuth se encuentran en `../backend/README.md`.
